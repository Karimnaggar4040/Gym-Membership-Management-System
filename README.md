# Gym Membership Management System

A Java-based application designed to efficiently manage gym memberships, trainers, and classes using Object-Oriented Programming (OOP) principles.

## ✅ Features

- Add, update, and delete gym members.
- Manage trainer information and assignments.
- Schedule and oversee gym classes.
- Data persistence through text files.
- Modular design adhering to OOP best practices.

## 🛠 Installation

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/Karimnaggar4040/Gym-Membership-Management-System.git

### 2. Import into IDE

- Open your preferred Java IDE (e.g., **IntelliJ IDEA**, **Eclipse**, or **NetBeans**).
- Choose **"Import Project"** and select the cloned folder.
- Make sure to import it as a standard Java project.

### 3. Build the Project

- Ensure the Java Development Kit (**JDK**) is installed (Java 8 or higher recommended).
- Configure the project SDK in your IDE settings if it’s not automatically detected.
- Build the project to ensure there are no compilation errors.


### 1. Run the Application

- Open your IDE.
- Navigate to the `src` directory.
- Run the `Main.java` file.

### 2. Interact with the System

- Use the console interface to:
  - Add new gym members.
  - Assign or view trainers.
  - Create and manage gym classes.

### 3. Data Storage

- All application data is saved in plain text files located in the project root:
  - `Members.txt`
  - `Trainers.txt`
  - `Classes.txt`
